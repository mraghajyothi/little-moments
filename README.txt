Little Moments upgrade — growth charts
1. Upload the files in this folder to the root of your GitHub Pages repository.
2. This version uses local browser storage. Export a JSON backup before changing versions if you want to keep records.
3. This app includes basic weight and length trend charts, profile, tracking logs, and backup/restore.
4. It does NOT calculate WHO percentiles or replace medical advice. WHO growth assessment requires validated age/sex-specific reference calculations.
5. The included icon-512.png is a placeholder. You may replace it with the icon artwork you selected earlier, keeping the filename icon-512.png.
