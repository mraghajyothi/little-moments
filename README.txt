LITTLE MOMENTS — STARTER APP

Included:
- Baby profile and automatic age calculation
- Daily feed, diaper, medicine, bath, and measurement logs
- Basic growth history
- Custom field definitions
- Local browser storage
- JSON backup/restore and CSV export
- Basic PWA manifest and offline service worker

IMPORTANT:
This is a starter prototype. Custom field definitions are saved, but custom values are not yet available through a dedicated entry form. Scheduled reminders, growth charts, and cloud backup are not implemented yet.

To use as an installable Home Screen web app on iPhone:
1. Host these files at an HTTPS address (for example, a private GitHub repository deployed with GitHub Pages, or another HTTPS static host).
2. Open the HTTPS site in Safari on your iPhone.
3. Tap Share > Add to Home Screen.
4. Open Little Moments from the Home Screen.

Data is saved in the browser's local storage on that device. Clearing website data can erase it. Use Export backup regularly. This prototype has not been security-audited and should not be used as the only record of medical information.
